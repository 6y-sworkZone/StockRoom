# 家庭物品库存管理系统

基于 Python + FastAPI + SQLite 开发的家庭物品库存管理 Web 应用。

## 功能特性

### 1. 用户系统
- 用户注册和登录
- JWT 身份认证
- 家庭成员邀请（生成邀请码）
- 一个用户可属于多个家庭
- 切换当前家庭上下文

### 2. 物品管理
- 添加物品（名称、类别、数量、单位、存放位置、购入日期、过期日期、价格、备注、照片）
- 编辑物品属性
- 删除物品（移入回收站）
- 批量导入物品（CSV 文件上传解析）
- 物品支持多规格（如：500ml、1L 等）
- 按类别和位置筛选物品

### 3. 位置管理
- 三级位置层级（房间→区域→具体位置）
- 支持增删改操作
- 物品列表可按位置层级逐级浏览

### 4. 出入库记录
- 每次数量增减自动生成流水记录
- 操作类型：入库、出库、消耗、丢弃、转移、调整
- 记录操作人、变更前数量、变更后数量、备注
- 支持手动补录历史记录

### 5. 过期预警
- 首页展示 30 天内即将过期和已过期物品列表
- 过期物品标红显示
- 支持按类别设置预警天数（如：食品默认提前 7 天预警，药品提前 30 天）

### 6. 统计面板
- 各类别物品数量和总价值占比饼图
- 月度出入库趋势折线图
- 各房间物品数量柱状图
- 低库存预警列表（数量低于设定阈值的物品）
- 使用 Chart.js 前端绘制图表

### 7. 购物清单
- 根据物品消耗速度和当前库存自动生成建议购物清单（基于近 30 天平均消耗量计算 7 天内可能耗尽的物品）
- 手动添加购物项
- 购物时勾选已购项自动入库
- 清单支持分享为文本

## 技术栈

- **后端**: Python 3.8+, FastAPI, SQLAlchemy 2.0
- **数据库**: SQLite（异步）
- **前端**: 原生 HTML + CSS + JavaScript, Chart.js
- **认证**: JWT (python-jose), passlib

## 安装和运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行应用

```bash
python main.py
```

或者使用 uvicorn 直接运行：

```bash
uvicorn main:app --host 0.0.0.0 --port 8765 --reload
```

### 3. 访问应用

在浏览器中打开：http://localhost:8765

## 使用说明

### 首次使用

1. 点击"注册"创建一个新用户
2. 登录后进入主页面
3. 点击"家庭"标签页创建一个家庭
4. 开始添加位置和物品

### 家庭成员邀请

1. 在"家庭"标签页点击"生成邀请码"
2. 将生成的邀请码分享给其他家庭成员
3. 其他成员注册登录后，在登录页面点击"输入邀请码"加入家庭

### 批量导入物品

准备 CSV 文件，支持以下列名（中英文均可）：
- name/名称
- category/类别
- quantity/数量
- unit/单位
- spec/规格
- price/价格
- remarks/备注
- low_stock_threshold/低库存阈值

## 端口说明

默认使用 8765 端口，避免与常用端口（8080、3000 等）冲突。

如需修改端口，编辑 `main.py` 文件最后一行：

```python
uvicorn.run(app, host="0.0.0.0", port=你想要的端口号)
```
